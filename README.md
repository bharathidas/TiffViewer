# Tiff Viewer
This module enables viewing of TIFF (Tagged Image File Format) files directly within your Mendix application using a modern, user-friendly viewer interface. It supports multi-page TIFFs, zoom, pan, and print functionality, offering a complete document viewing experience.

## Features:
### •	TIFF File Rendering – 
Supports both single-page and multi-page TIFF images.
### •	Zoomable & Printable – 
Built-in zoom and print controls.
### •	Pagination – 
Easily navigate through multi-page TIFF files.
### •	Language Support – 
Multilingual support (EN, DE, FR, ES, TR).
### •	Custom UI – 
Button color customization and responsive layout

## Dependencies:
•	Mendix modeler 10.18.3.
